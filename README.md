# 🛍️ BuzzBuy – Responsive Shopping Website

A modern and responsive **shopping website UI** built using **HTML, CSS, and JavaScript**.
BuzzBuy provides a clean e-commerce-style interface with product sections, categories, offers, newsletter subscription, and a responsive navigation menu.

## 🚀 Live Demo

🔗 **Live Demo:**
https://prashantbuildsdev-dev.github.io/responsive-shopping-website/

## 📌 Features

* 📱 Fully Responsive Design
* 🧭 Responsive Navigation Bar
* 🍔 Mobile Hamburger Menu
* 🛍️ Shopping Cart UI
* 👕 Men's, Women's & Kids Categories
* 👜 Product Showcase
* 💰 Sale & Discount Sections
* 🆕 New Products Section
* 📦 Add to Cart Buttons
* 📰 Latest Trends / Blog Section
* 📧 Newsletter Subscription UI

* ✨ Clean and Modern UI

## 🏠 Website Sections

### 1. Navigation Bar

The website includes a navigation bar with:

* Home
* Shop
* Page
* Blog
* Contact
* Search icon
* User icon
* Shopping bag icon
* Mobile hamburger menu

The project uses Font Awesome for the navigation icons.

### 2. Hero Section

The hero section highlights the latest fashion collection with a promotional offer and **Shop Now** button.

### 3. Categories

Users can explore different shopping categories:

* Men's
* Women's
* Kids
* Accessories

### 4. New Products

A dedicated product section displays product images, names, prices, sale prices, and **Add to Cart** buttons.

### 5. Women's Collection

A promotional section highlights the **Women's Collection** with a seasonal trend and shopping CTA.

### 6. Best Sale

The Best Sale section displays multiple products with regular and discounted prices.

### 7. Services

The website highlights:

* Free Shipping
* Cash on Delivery
* Gift Offers
* Opening Hours

### 8. Latest Trends / Blog

A latest-news section is included to showcase fashion trends and blog content with **Read More** links.

### 9. Newsletter

Users can enter their email and subscribe to the newsletter. Social media icons are also provided.

### 10. Footer

The footer contains useful links such as:

* About Us
* Online Store
* Blog
* Contact Us
* Login / Register
* Cart
* Wishlist
* FAQs
* Privacy Policy
* Returns

It also contains BuzzBuy contact information.

## 💻 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/PrashantBuildsDev/responsive-shopping-website.git
```

2. Open the project folder:

```bash
cd responsive-shopping-website
```

3. Open `index.html` in your browser.

Or use **Live Server** in VS Code for a better development experience.
